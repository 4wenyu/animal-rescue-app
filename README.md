# 🐾 Animal Rescue Management Hub

A high-fidelity, premium SaaS-style dashboard designed for animal rescue operations. This application centralizes shelter logistics, dog intake statuses, medical tracking, and operational metrics into a single, high-performance web interface.

## 🚀 Key Features

- **Dynamic Metrics Engine:** Automatically computes shelter health metrics (Total Dogs, Healthy, Needs Review, Average Age) directly from active JSON datasets.
- **SaaS Dark-Mode Sidebar:** Full-height layout with smooth micro-interactions, responsive navigation layout, and real-time active state tracking.
- **Buttery Smooth Animations:** Powered by `framer-motion` using custom spring physics and staggered layout animations for an elite fluid feel.
- **Robust Type Safety:** Built entirely with strict TypeScript, guaranteeing clean builds and smooth data structures.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
